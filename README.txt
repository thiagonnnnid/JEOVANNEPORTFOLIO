PORTFÓLIO DO PROFESSOR JEOVANNE — LÍNGUA PORTUGUESA

Arquivos:
- index.html: estrutura e conteúdo do site
- style.css: cores, layout e responsividade
- script.js: menu móvel e interação dos temas
- assets/: fotos fornecidas para o portfólio

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP.
2. Abra a pasta portfolio_professor_jeovanne no VS Code.
3. Abra o arquivo index.html no navegador. Você também pode usar a extensão Live Server.
4. Para alterar textos, edite o index.html. Para cores e aparência, edite style.css.
5. Para adicionar temas interativos, edite o objeto "topics" no script.js.

Observação:
O texto biográfico é genérico e demonstrativo, sem inventar formação, experiência ou dados pessoais do professor. Revise e personalize conforme as informações reais.
